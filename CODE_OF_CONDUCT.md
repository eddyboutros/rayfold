# Code of conduct

Rayfold adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for every space the project runs: issues, pull requests, discussions and any chat the project
opens.

In short: be welcoming and patient, criticise ideas rather than people, and assume good intent. Harassment, personal
attacks and publishing someone's private information are not accepted.

## Reporting

Report conduct problems privately to the maintainer through [GitHub](https://github.com/eddyboutros) or, for anything
security-related, through the private channel in [SECURITY.md](SECURITY.md). Reports are kept confidential. The
maintainer may warn, temporarily ban or permanently ban anyone whose behaviour breaks this code, following the
Contributor Covenant's enforcement guidelines.
